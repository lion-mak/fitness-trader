# 微信小程序 · 认证与备案操作清单

> 项目：健身交易员　AppID：`wx6d6df602a239f29e`　主体：个人
> 编写日期：2026-09-17　目标：11 月上旬提交审核

---

## 零、先记住这个顺序（最容易踩的坑）

```
注册账号  →  ① 微信认证  →  ② 填小程序信息 + 选类目  →  ③ 提交小程序备案  →  ④ 开发上传  →  ⑤ 提审发布
```

**必须「先认证」才能填类目、才能进备案入口。** 很多人注册完直接去找备案，发现入口是灰的点不动 —— 不是系统坏了，是顺序错了。

---

## 一、微信认证（付费，**卡在关键路径最前端，最先做**）

### 准备材料

- [ ] 身份证正反面照片（清晰、无反光、无遮挡、四角完整）
- [ ] 本人实名手机号（**必须能接电话** —— 第三方审核公司会打电话核实，漏接会卡住）
- [ ] 常用邮箱
- [ ] 身份证号、姓名（与身份证完全一致）

### 操作步骤

1. 登录 [mp.weixin.qq.com](https://mp.weixin.qq.com)，扫码进小程序后台
2. 首页找到 **【微信认证】** 模块 → 点【去认证】
3. 阅读审核说明 → 继续点【去认证】
4. 机构类型选 **「个体工商户」或「个人」**（按账号实际主体类型选）
5. 填写认证联系人信息：姓名、身份证、联系电话 → 收短信验证码 → **联系人微信扫码核验**
6. 填写发票信息（选电子发票即可）
7. 付费 -> **个人 / 个体户 30 元**（每年年审制；企业为 300 元/次）
8. 提交后等第三方机构审核

### 时效与费用

| 项目 | 说明 |
|---|---|
| 费用 | **30 元**（个人/个体户，按年审制；企业 300 元/次） |
| 审核时长 | **1–5 个工作日** |
| 注意 | **审核不通过费用不退**，材料务必一次到位 |
| 注意 | 第三方审核公司会打电话核实，保持手机畅通 |

## 二、小程序信息与类目（认证通过后立刻做）

- [ ] **小程序名称**：先查「健身交易员」是否被占用。名称全局唯一，被占用就得换。
      ⚠️ 名称要填进备案，且认证后改名麻烦 —— 定名称这一步先想清楚再提交。
- [ ] **小程序头像**：png/jpg，≤2M，推荐 144×144。可直接用 `assets/icon.png`（需压到 2M 内）
- [ ] **小程序简介**：一句话说清是什么（"把减肥做成炒股游戏的健康记录工具"）
- [ ] **服务类目**：选 **「工具 → 健康管理」**

### 类目红线（务必避开）

| 不能选 | 原因 |
|---|---|
| 医疗、健康咨询 | 需行业资质，个人主体开不了，且触发前置审批 |
| 金融、证券、投资 | 个人主体禁止，且与我们只是"交易隐喻"无关 |
| 社交、社区 | 需 ICP 许可证 |

> 我们只是"用股票隐喻做健康记录"，**类目必须落在「工具」，绝不能碰医疗和金融**。类目选错是备案驳回最高频的原因。

## 三、小程序备案（免费，**这里是不可压缩的日历时间**）

### 准备材料（个人主体只需本人资料）

- [ ] **有效期内的身份证正反面照片** —— 清晰、无反光、无遮挡、四角完整露出
- [ ] **本人实名办理的手机号**（必须能接收工信部 12381 核验短信）
- [ ] **常用邮箱**
- [ ] **精确到门牌号的通讯地址**（户籍地或长期居住地均可）
      ⚠️ 只写到街道/小区会**直接驳回**
- [ ] ⚠️ 若身份证地址与备案省份不一致，**部分省份要求提供居住证** → 提前查所在省管局规则
- [ ] 人脸核验准备：**纯白背景**（白墙最佳，避免拍到墙角、门缝、杂物），本人出镜，环境安静

### 操作步骤

1. 小程序后台 → 侧边栏 **设置 → 小程序备案 → 【去备案】**
   （若已收到站内提醒，后台顶部也有【去备案】快捷入口）
2. **填主体信息**
   - 主办单位性质：**个人**
   - 姓名（与身份证完全一致）、身份证号
   - 证件住所（身份证上的地址）、通讯地址（实际居住地，**精确到门牌号**）
   - 负责人手机号、电子邮箱
   - ⚠️ 负责人必须是**主体本人**，不能填其他人
3. **填小程序信息**
   - 小程序名称（自动带出 AppID）
   - 服务类目（与第二步选的一致）
4. **真实性核验**
   - 按提示完成**本人人脸视频核验**，不能代操作
   - 签署《互联网信息服务承诺书》
5. **提交 → 微信平台初审**（1–6 个工作日，周末节假日不算）
6. **工信部短信核验**
   - 收到 **12381** 短信后，**在短信写明的时间内核验**（通行要求 24 小时内，务必当天就做）
   - 点短信内官方链接 → 跳工信部备案政务平台 → 输入验证码 + 身份信息 → 提交
   - ⚠️ **超时不核验 = 备案失效，要从头重来**
7. **通信管理局终审**（1–20 个工作日，全国平均 7–15 个工作日）

### 时效汇总

| 环节 | 时长 |
|---|---|
| 微信平台初审 | 1–6 个工作日 |
| 工信部短信核验 | 24 小时内（当天做掉） |
| 通管局终审 | 1–20 个工作日（平均 7–15） |
| **合计** | **最快约 2 周，常见 3–4 周** |

## 四、时间倒推表（以 11 月上旬提审为目标）

| 时间 | 动作 | 为什么这个时间点 |
|---|---|---|
| **9 月底 – 10 月第一周** | 提交微信认证（30 元） | 认证 1–5 工作日，且**认证不通过备案入口就打不开** |
| **10 月第一周** | 配置名称 + 类目 | 认证通过后立刻做，不能再等 |
| **10 月第二周前** | 提交小程序备案 | **关键路径**：备案 2–4 周，晚一周提交就晚一周上线 |
| 10 月 | 认证/备案审核期，并行开发 | 这段时间用来做小程序骨架 + 云数据库 |
| 11 月上旬 | 提交审核发布 | 提审到通过还要 1–7 天，可能被要求整改 |

> **核心提醒**：备案是唯一无法用加班压缩的环节。今天 9/17，10 月第一周是死线 —— 晚一周启动，11 月上线就要推迟。

## 五、高频驳回原因自查（提交前逐条对一遍）

- [ ] 跳过认证直接找备案入口 → 入口不可用
- [ ] 服务类目与实际功能不符 → **最高频驳回原因**
- [ ] 通讯地址未精确到门牌号 → 直接驳回
- [ ] 身份证照片反光 / 遮挡 / 缺角 → 驳回重提，每次重提都是好几天
- [ ] 人脸核验背景有杂物、不是纯白 → 核验失败
- [ ] 漏接第三方审核公司电话（认证阶段）→ 卡住甚至驳回
- [ ] 工信部短信 24 小时内未核验 → 备案失效重来
- [ ] 身份证地址与备案省份不一致但未提供居住证 → 部分省份驳回

- [ ] 停止服务 → 办理注销手续
- [ ] 一个身份证最多备案 **5 个**小程序（当前用 1 个）

## 八、一句话总结

**认证（30 元 / 1–5 天）→ 类目（工具-健康管理）→ 备案（免费 / 2–4 周 / 不可压缩）**，三步顺序不能乱，其中备案是唯一会卡死上线日期的一环，10 月第一周必须启动。
