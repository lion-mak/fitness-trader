## 二、硬技术规格（方案 A 用）

| # | 要求 | 为什么 |
|---|---|---|
| 1 | **纯洋红底 `#FF00FF`** 铺满整张，四角无杂色 | 透明底**实测会被渲染成棋盘格像素**（PNG 无 alpha 通道），抠图两轮才干净；洋红底一次抠净。白/黑底会抠出毛边 |
| 2 | **前景绝不用洋红**（不用品红/玫红/洋红系） | 抠图按色相判据删洋红，前景同色会被误删成洞 |
| 3 | **无文字 / 无数字 / 无水印 / 无签名** | 生图水印实测占右下角 7~8% 像素，会被当角色留下来；我虽有强制剔除，但别给它机会 |
| 4 | **无边框 / 无相框 / 无地面投影** | 墙面阴影会在抠图后留一圈灰脏（踩过：韭菜底部一排灰虚线） |
| 5 | 正方形 **1024×1024**（≥512 即可），PNG | 上游给我 512 就够（我会缩到 512 存源）；给大的更好 |
| 6 | 角色**居中、完整可见**，四周留 ~12% 边 | 贴边会被裁掉；我的夹具按 bbox 裁，留边能防裁切 |
| 7 | 角色占画面 **60~75%** | 太小上卡显弱，太大没留白 |
| 8 | 轮廓**强、细节少** | 卡上实际只显示 **122px 宽**（下面第四节），碎细节必糊成色块 |

## 四、显示尺寸（决定了角色要画多"粗"）

| 项 | 值 | 出处 |
|---|---|---|
| 基准视口 | 430 px | 全项目 rect 闸基准 |
| 页面左右留白 | 14 px | 沿用 `.rank-hero` |
| 三列间距 | 18 px | 你定的"间距大一点没关系" |
| **单卡** | **122×171 px** | (430 − 28 − 36) / 3 = 122；比例 0.713 ≈ 实体交易卡 2.5:3.5 |
| 卡上**角色区** | 106×117 px | 卡面三段式中间那块 |
| 出图（@3x） | 366×513 | 实际渲染 3 倍 |

**可读性实测**（上一版 11 张的实测数据，供你出图参考）：

| 卡宽 | 角色 | 中文称谓 |
|---|---|---|
| 140px | 五官清楚 | 极清楚 |
| **122px（目标）** | 五官可辨 | **清楚** ✓ |
| 96px | 糊成色块 | 仍完全可读 ✓ |
| 72px | 只剩轮廓 | 认得出字形 |

⇒ 结论：**角色只需要"认得出来是什么"，不需要细节**。造型靠**剪影 + 一个标志性道具**取胜。
